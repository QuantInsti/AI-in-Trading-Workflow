### Setup

For the complete and official setup instructions, please refer to the [Gemini Fullstack LangGraph Quickstart GitHub repository](https://github.com/google-gemini/gemini-fullstack-langgraph-quickstart).

The setup process involves the following prerequisites:
- Node.js and npm
- Python 3.11+
- A Google Gemini API Key

You will need to clone the repository, install both Python and Node.js dependencies, and configure your environment variables as described in the repository's `README.md` file.

### Usage

Once the setup is complete, you can run the application using the instructions in the repository. This typically involves running the backend and frontend servers.

You will also need to set your Google API key as an environment variable. You can get a key from the Google AI Studio.

```bash
export GOOGLE_API_KEY="YOUR_API_KEY"
```

Replace `"YOUR_API_KEY"` with your actual API key.




This directory demonstrates how to build and interact with full-stack, AI-driven trading applications using Google’s Gemini models and the LangChain framework.

A “full-stack” approach in this context refers to the entire application, from the front-end client to the back-end agentic systems. LangChain is a framework that simplifies the development of applications powered by language models, including complex chains and multi-agent systems.

### Full-Stack LangChain Approach

* **Structured Development:** LangChain provides a modular structure for building complex AI applications.

* **Agent-Based Systems:** It can be used to create multi-agent systems where different AI agents collaborate.

* **End-to-End Solutions:** This approach covers the entire process from user query to the final output generated by the AI system.
