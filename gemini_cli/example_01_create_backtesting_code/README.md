This directory contains a backtesting setup for a moving average crossover strategy applied to Bitcoin (BTC-USD).

The process tests a trading strategy, finds its optimal parameters, and runs a simulation. The included Python script captures the process.

### Backtester Functionality

1.  **Data Download**: Fetches historical Bitcoin data from Yahoo Finance.
2.  **Strategy Optimization**: Runs an optimization process on the first 90% of the historical data to find the best-performing short-term and long-term moving average windows based on the Sortino Ratio.
3.  **Event-Driven Backtest**: Uses the optimal parameters to run an event-driven backtest on out-of-sample data (the most recent 10% of the data), including a stop-loss and take-profit.
4.  **Reporting**: Generates a PDF report summarizing the backtest performance with key metrics and charts.

### Files in This Directory

*   `bitcoin_strategy_backtest.py`: The full backtesting process as a Python script.
*   `backtest_report.pdf`: An example of the final PDF report generated by the script.
*   `equity_curve.png` & `drawdown.png`: Chart images the script generates, showing the strategy's performance and drawdown.
*   `requirements.txt`: A list of Python libraries required to run the backtesting script.

### How to Run the Script

1.  **Install Dependencies**: Before you run the script, you must install the necessary libraries. You can install them using pip and the `requirements.txt` file:
    ```bash
    pip install -r requirements.txt
    ```

2.  **Execute the Script**: Run the backtesting script from your terminal:
    ```bash
    python bitcoin_strategy_backtest.py
    ```

    The script will download the data, run the optimization and backtest, and generate a `backtest_report.pdf` with the results.

### Next Steps and Experimentation

This project is a starting point. To deepen your understanding, we strongly recommend the following activities:

*   **Tweak the Prompts:**
    *   Consult the `how_to...` file and modify the prompts given to the Gemini CLI. Ask for a different trading strategy, such as one based on the Relative Strength Index (RSI).
    *   Request different performance metrics for the final report, like the Calmar or Omega Ratios.

*   **Tweak the Code:**
    *   Change the asset being tested from `'BTC-USD'` to a stock like `'NVDA'` or an ETF like `'SPY'`. How does the strategy perform on different asset classes?
    *   Adjust the optimization parameters. What happens if you search a wider or narrower range of moving average windows?

*   **Extend the Project:**
    *   Prompt the LLM to add a section to the script that performs a Monte Carlo simulation on the backtest results to assess their statistical significance.
    *   Ask the LLM to add functionality for multi-asset backtesting to see how a portfolio of assets would have performed.
